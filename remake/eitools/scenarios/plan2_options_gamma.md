## План исправления

### P2-T1: разобрать применение Gamma/Contrast/Brightness в game.exe — сделано 2026-11-11
Найдено: поля `+0x8c/+0x90/+0x94` объекта 79bc60 — это Brightness, Contrast, Gamma, float в
[-1, 1] (459100, реестр `Software\Nival Interactive\EvilIslands\General Settings`). Край ручки
максимума записывает 1.0, середина — 0.0. `FUN_00504a60` строит таблицу гаммы 3 x 256 слов,
одинаковую для трёх каналов: яркость делится на 2; контраст даёт множитель `1 + 4|c|`
(`1 / множитель` при c < 0) и смещение `(1 - множитель) / 2`; гамма даёт показатель
`1 / (1 + 2.5g)` при g > 0 и `1 / (1 + 0.25g)` при g < 0; значение
`((i / 255) ** показатель * множитель + смещение + яркость)` зажимается в 0..1.
Таблица уходит в `IDirectDrawGammaControl` (виртуальный вызов +0x10), то есть только в полный
экран. Формула записана в docstring `engine/options.py`.

### P2-T2: научиться видеть гамму оригинала — сделано 2026-11-11
Проверено на `:77`: FullScreen=1 (умолчание game.exe без реестра), ручка Gamma на максимуме,
`xrandr --verbose` — `Gamma: 1.0:1.0:1.0`. Wine не передаёт гамму DirectDraw в X-сервер, поэтому
в нашей связке оригинал картинку не меняет; снимок её тоже не содержит. Отдельная команда
`expect_gamma` не нужна.

### P2-T3: применить гамму в демо — снято
В условиях проверки оригинал гамму не применяет, поэтому демо, применяющее её, дало бы новое
различие на кадрах. Значения хранятся; формула из P2-T1 готова для P28, когда появится
полноэкранный проход постобработки.
