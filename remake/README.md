# Evil Islands remake (Python + Kivy)

Исследовательский аналог движка «Проклятых Земель». Читает данные оригинальной игры и повторяет её
поведение там, где оно восстановлено из `game.exe`. Что найдено в коде игры, описано в [first_scan.md](first_scan.md).

Проект отдельный от основного (`../src`): своя виртуальная среда, свои зависимости, свои пакеты.

## Установка

```bash
cd remake
make venv            # python3.12 -m venv venv && pip install -r requirements.txt
export EI_DATA_PATH=/run/media/veselin/STUFF/evil_islands/EvilIslands/ENG/game_info/data
make test
```

`EI_DATA_PATH` — папка игры, в которой лежат `game.exe`, `res/` и `maps/`.
Если переменная не задана, используется путь из `eilib/gamedata.py: DEFAULT_DATA_PATH`.

## Запуск

Главная команда — `make demo`: игра запускается как game.exe, с главного меню, и показывает всё, что ремейк уже
умеет. «New game» ставит одетого героя на zone1 туда же, где игра начинается по сценарию (вход 1 зоны gz1g
в map.txt). У героя есть книга готовых заклинаний и смена оружия, F1 показывает клавиши. Кнопки, которых
ещё нет, отвечают «not made yet».

```bash
make demo                     # главное меню → New game → zone1 с героем, его оружием и заклинаниями
make menu                     # только главное меню; «New game» открывает --start-map
make model NAME=unhuma        # просмотр модели и всех её анимаций
make map NAME=bz10k           # карта с объектами из .mob и управляемым юнитом
PYTHONPATH=src venv/bin/python -m client.main map zone19 --unit unorma --weapon AXE
PYTHONPATH=src venv/bin/python -m client.main model unhuma --prototype "Human Kania Citizen F8" \
    --item "hadagan high2 helm.adamantium" --item "hadagan high2 plate.adamantium" --item "saber.steel"
PYTHONPATH=src venv/bin/python -m client.main map zone8 --position 232,138   # орки с топорами и луками
PYTHONPATH=src venv/bin/python -m client.main map zone1 --position 140,100 --hour 21   # вода и вечерний свет
PYTHONPATH=src venv/bin/python -m client.main map zone1 --position 60,60 --distance 40 --pitch 12   # туман и небо
PYTHONPATH=src venv/bin/python -m client.main map zone1 --position 61,101 --prototype "Human Hero" \
    --spell "Lightning Arc"   # Ctrl + клик по кабану — молния
PYTHONPATH=src venv/bin/python -m tools.snapshot figure unhuma uattack04 --frame 12 -o pose.png   # без OpenGL
```

Управление:

| Режим | Клавиши и мышь |
|---|---|
| Модель | ←/→ — предыдущее/следующее действие из `.adb`, B — другое телосложение |
| Карта | клик — идти, Shift+клик — бежать, клик по юниту — атака, Ctrl+клик по юниту (или по земле для заклинания точки) — заклинание `--spell`, стрелки — сдвиг камеры, Q/E — поворот камеры |
| Карта, действия | 1 атака, 2 каст, 3 получение урона, 4 смерть, 5 особое, 0 idle |
| Карта, время | `[` / `]` — час суток на полчаса назад/вперёд, T — быстрое время (час за 10 секунд) |
| Карта, меню | Esc — колонна Esc-меню («Return to game» закрывает, «Exit to main menu» — в главное меню) |
| Карта, панели | правый нижний диск — пауза, обычная и быстрая скорость, центр — карта аллода и журнал квестов; левый — шагом/бегом; кнопки слева у окна информации — его режимы; R — области кнопок, H — отладочный текст; подсказки как в игре |
| Карта, раны | L — ранить ноги героя (хромая ходьба, без бега), ещё раз — вылечить |
| Карта, предметы | I — полоса предметов героя (вещи из `--item`): стрелки по краям листают (зажать — дальше, Shift — в начало/конец), шесть кнопок — категории; K — лагерь: четверти партии, окна информации, навыков, торговли, ремонта и конструкторов |
| Демо | F1 — клавиши; Z/X — предыдущее/следующее заклинание книги (24 готовых), Ctrl+клик — по монстру или земле, C — на героя; W — следующее оружие (меч, топор, копьё, лук, арбалет, без оружия); M — полные мана и здоровье |
| Главное меню | наведение — камень кнопки выдвигается, клик — New game / Exit, R — показать области кнопок |
| Везде | пробел — пауза, F — быстрый тик 27 мс, мышь — вращение камеры, колесо — зум, Esc — выход (кроме карты) |

## Что уже повторяет оригинал

- Анимации: время в кадрах, lerp позиций, slerp поворотов по кратчайшему пути, удержание последнего ключа.
- Кости: «родитель × трек», смещения детей из `.bon` по телосложению, смещения корня × масштаб юнита.
- Плеер: зацикливаются только клипы со стадией CYCLE, остальные держат последний кадр, очередь клипов.
- Время: тик 55 мс (≈18.18 кадра анимации в секунду), быстрый режим 27 мс, ограничение шага 500 мс.
- Выбор действия: маска оружие|состояние|тип|модификатор|стадия, запасные варианты, вес `action_probability`.
- Движение: высота по рельефу, поворот `exp(−0.3·dt)`, скорость за тик из `units.udb` / `UNIT_STATS`,
  темп анимации по формуле клиента (`movement_speed · размер / 7.5`),
  клип START перед циклом ходьбы и бега, хромота и запрет бега при раненых ногах (`ai.reg`).
- Характеристики: `UNIT_STATS` карты и прототипы `units.udb` (здоровье, мана, атака, защита, урон, броня).
- Путь: сетка сервера в полклетки, коды проходимости для 8 классов роста (вода, обрывы, тайлы из `tileDesc.reg`),
  цены шагов по склону, объекты карты как препятствия и полы, штраф поворотов; клик на карте ведёт героя в обход реки, скал и домов.
- Карты: ландшафт с правильной раскладкой тайлов, деревья, здания и юниты из `.mob`.
- Экипировка: части брони и оружия, шлем поверх головы и без волос, две текстуры юнита
  (тело и снаряжение) склеены из слоёв `redress.res` в порядке `game.exe`, кожа и причёска из `units.udb`.
- Свет: цвета солнца, рассеянного света и неба по часам из `config/lights*.ini`, путь солнца,
  туман день/ночь, пещеры; час из `WS_TIME`.
- Вода: материалы `.mp`, прозрачность, волны и покачивание от ветра `WORLD_SET`, блики на гребнях.
- Главное меню: карта `ZoneMainMenuNew` с камерой `MainMenu.cam`, колонна с надписями (вторая текстура частей),
  кнопки из `menus.reg`, камни выдвигаются анимациями `.adb`, текст версии. Esc-меню: колонна в 3D-интерфейсе
  поднимается и опускается. Курсор игры (кадры по 125 мс), шрифты интерфейса как в игре.
- Экран боя: окно информации, текстовое окно, миникарта (карта зоны из `#maps` в `map.txt`, метки юнитов,
  компас, масштаб кнопками), диск паузы и скорости (кольцо дня поворачивается
  с часом), диск режимов, портрет героя с 3D-головой и полосами. Всё — элементы 3D-интерфейса по глубине,
  подсказки из `texts.res` (раздел 20 `first_scan.md`).
